# Java Practice

[Back to main project](../README.md)

This module is for practicing core Java concepts before applying them in larger projects.

## Topics To Practice

| Topic | What To Add |
| --- | --- |
| Java basics | Syntax, control flow, methods, classes, and objects. |
| OOP | Encapsulation, inheritance, polymorphism, abstraction, and composition. |
| Collections | List, Set, Map, Queue, generics, sorting, and iteration. |
| Exceptions | Checked exceptions, unchecked exceptions, custom exceptions, and error handling. |
| Streams | Stream operations, collectors, lambdas, and method references. |
| Concurrency | Threads, executors, synchronization, locks, and concurrent collections. |
| JVM basics | Memory model, garbage collection notes, and performance observations. |

## Suggested Structure

Create topic-based packages under `src/main/java`, for example:

```text
com.software.practice.java.collections
com.software.practice.java.streams
com.software.practice.java.concurrency
```

Each package should include a `PACKAGE.md` file explaining the examples in that package.

## Notes

- Keep examples small and focused.
- Prefer names that explain the concept being practiced.
- Add tests for reusable examples and edge cases.
