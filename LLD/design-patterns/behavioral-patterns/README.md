# Behavioral Patterns

[Back to design patterns](../README.md)

This module is for practicing patterns that organize communication and responsibility between objects.

## Patterns To Practice

| Pattern | Purpose |
| --- | --- |
| [Chain of Responsibility](src/main/java/patterns/behavioral/chainofresponsibility/PACKAGE.md) | Pass a request through handlers until one handles it. |
| [Command](src/main/java/patterns/behavioral/command/PACKAGE.md) | Encapsulate a request as an object. |
| [Iterator](src/main/java/patterns/behavioral/iterator/PACKAGE.md) | Traverse a collection without exposing internals. |
| [Mediator](src/main/java/patterns/behavioral/mediator/PACKAGE.md) | Reduce direct dependencies between objects. |
| [Memento](src/main/java/patterns/behavioral/memento/PACKAGE.md) | Capture and restore object state. |
| [Observer](src/main/java/patterns/behavioral/observer/PACKAGE.md) | Notify dependents when state changes. |
| [State](src/main/java/patterns/behavioral/state/PACKAGE.md) | Change behavior when internal state changes. |
| [Strategy](src/main/java/patterns/behavioral/strategy/PACKAGE.md) | Swap algorithms behind a common interface. |
| [Template Method](src/main/java/patterns/behavioral/templatemethod/PACKAGE.md) | Define an algorithm skeleton with customizable steps. |
| [Visitor](src/main/java/patterns/behavioral/visitor/PACKAGE.md) | Add operations to object structures without changing their classes. |

## Practice Template

For each pattern:

1. Add a package named after the pattern.
2. Explain the collaboration between objects.
3. Add a demo flow in code.
4. Document where the pattern is useful and where it may be too much.
