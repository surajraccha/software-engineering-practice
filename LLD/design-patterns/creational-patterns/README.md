# Creational Patterns

[Back to design patterns](../README.md)

This module is for practicing patterns that control object creation.

## Patterns To Practice

| Pattern | Purpose |
| --- | --- |
| [Singleton](src/main/java/patterns/creational/singleton/PACKAGE.md) | Ensure one shared instance where appropriate. |
| [Factory Method](src/main/java/patterns/creational/factorymethod/PACKAGE.md) | Let subclasses or factory methods decide which object to create. |
| [Abstract Factory](src/main/java/patterns/creational/abstractfactory/PACKAGE.md) | Create related families of objects without binding to concrete classes. |
| [Builder](src/main/java/patterns/creational/builder/PACKAGE.md) | Construct complex objects step by step. |
| [Prototype](src/main/java/patterns/creational/prototype/PACKAGE.md) | Create new objects by copying existing objects. |
