# Creational Patterns

[Back to design patterns](../README.md)

This module is for practicing patterns that control object creation.

## Patterns To Practice

| Pattern | Purpose |
| --- | --- |
| Singleton | Ensure one shared instance where appropriate. |
| Factory Method | Let subclasses or factory methods decide which object to create. |
| Abstract Factory | Create related families of objects without binding to concrete classes. |
| Builder | Construct complex objects step by step. |
| Prototype | Create new objects by copying existing objects. |

## Practice Template

For each pattern:

1. Add a package named after the pattern.
2. Add a small real-world example.
3. Add a README or package note explaining the pattern.
4. Add tests or a runnable demo.
