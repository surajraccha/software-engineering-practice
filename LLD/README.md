## Topics To Practice

- Object-oriented design.
- SOLID principles.
- UML-style class relationships.
- Design patterns.
- Clean interfaces and abstractions.
- Real-world machine coding exercises.

## Documentation Pattern

For every design exercise:

1. Explain the problem statement.
2. List requirements and assumptions.
3. Document the main classes and responsibilities.
4. Add important design decisions.
5. Add examples or tests showing behavior.
